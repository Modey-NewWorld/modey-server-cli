# Politique de Sécurité — Modey Server CLI

## Signalement de Vulnérabilités

La sécurité de l'infrastructure Modey et de ses serveurs de jeux est une priorité absolue. Si vous découvrez une vulnérabilité ou une faille de sécurité relative à `modey-server-cli` ou aux protocoles de communication avec la plateforme centrale :

1. **Ne créez pas d'issue publique** sur GitHub pour divulguer la faille.
2. Envoyez un rapport détaillé par email à **contact@flowcrea.fr**.
3. Vous pouvez également contacter directement l'auteur via GitHub Security Advisory : [@NayrolfRdgs](https://github.com/NayrolfRdgs).

Merci de préciser :
- La version de Node.js et du CLI utilisée.
- Les étapes détaillées pour reproduire le problème.
- L'impact potentiel sur le serveur ou le réseau Modey.

Nous nous engageons à accuser réception sous 48 heures et à déployer un correctif dans les plus brefs délais.
